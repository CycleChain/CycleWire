Popular libraries, loaded by CycleWire

A server-rendered dashboard that works without JavaScript. Each library below is downloaded the first time it is needed, by the action that uses it; check wire.loaded() in the console.

Flatpickr: a date picker on first focus

A plain text input until you focus it. Then CycleWire loads Flatpickr and its stylesheet, and the calendar opens.

SweetAlert2: confirm before a destructive submit

Without JavaScript the form simply posts. With CycleWire it asks first, then sends the form in the background. SweetAlert2 loads on the first submit.

jQuery: an activity log

The page's existing jQuery code listens to CycleWire's cw:done events. The Undo buttons it inserts are CycleWire actions, live without any wiring.
